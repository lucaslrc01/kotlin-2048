# 2048

Aplicativo Android do jogo 2048, no qual o jogador desliza e combina blocos de mesmo valor até alcançar o bloco 2048.

O projeto foi desenvolvido para a disciplina de Programação para Aplicativos Móveis do curso de Análise e Desenvolvimento de Sistemas do IFSC. Seu objetivo é aplicar conceitos de desenvolvimento Android com Kotlin, Jetpack Compose, gerenciamento de estado e separação de responsabilidades.

## Tecnologias

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## Como executar

Abra o projeto no Android Studio, aguarde a sincronização do Gradle e execute o módulo `app` em um emulador ou dispositivo Android com API 24 ou superior.
